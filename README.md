Lancer l’Application

Pour démarrer l’application, suivez ces étapes dans l’ordre :

1. Backend

Placez-vous dans le dossier backend.

Suivez les instructions du README présent dans ce dossier pour lancer le backend.

2. Frontend

Une fois le backend lancé, placez-vous dans le dossier frontend.

Suivez le README du frontend pour démarrer l’interface utilisateur.

3. Tests Playwright

Pour exécuter les tests Playwright, placez-vous dans le dossier TestPlaywright.

Le README présent dans ce dossier contient la documentation pour lancer les tests.
