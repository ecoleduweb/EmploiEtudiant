# Portail d'offres d'emploi — Cégep de Rivière-du-Loup

Bienvenue sur le dépôt officiel du Portail d'offres d'emploi du Cégep de Rivière-du-Loup.  
Cette plateforme a été conçue pour centraliser et faciliter la mise en relation entre les recruteurs et la relève issue de notre établissement.

---

## Présentation du projet

Ce portail est le fruit d'une collaboration concrète entre le milieu académique et le monde professionnel.  
Il permet d'afficher des opportunités de carrière ciblant spécifiquement :

- Les élèves actuels (stages, emplois d'été, temps partiel)
- Les nouveaux diplômés (entrée sur le marché du travail)

---

## Une initiative pédagogique

Le développement de cette application a été réalisé par les étudiants du programme Techniques de l'informatique,  
sous la supervision de l'enseignant Antoine Chagnon-Michaud.

## Lancement de l’application

Pour démarrer l’application, suivez les étapes ci-dessous dans l’ordre :

### 1. Backend

Placez-vous dans le dossier :  
backend/API  

Suivez les instructions du README présent dans ce dossier pour lancer le backend.

---

### 2. Frontend

Une fois le backend lancé, placez-vous dans le dossier :  
frontend/projet_application  

Suivez le README du frontend pour démarrer l’interface utilisateur.

---

### 3. Tests Playwright

Placez-vous dans le dossier :  
TestPlaywright  

Consultez le README pour lancer les tests et vérifier le fonctionnement global de l’application.

---

### 4. GitHub Actions

Pour obtenir de l’aide concernant le système de déploiement et de build GitHub Actions :

Placez-vous dans le dossier :  
.github  

Consultez le fichier :  
GITHUB_GUIDE.md
